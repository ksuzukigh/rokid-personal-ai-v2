# AIと一緒に作るための開発依頼

以下を、開発を手伝うAIへ渡してください。このリポジトリの資料も読めるようにします。最初は接続・権限・実装できる範囲を調べ、Mac内の専用テスト会話から始めます。

## 自分の条件を記入する

| 項目 | 記入する内容 |
| --- | --- |
| 使う眼鏡 | 機種、OS、AIUIの利用可否 |
| Mac | OS、開発環境、常設稼働できる条件 |
| AI | 利用しているアプリ・CLI、アカウント、使える接続方法 |
| 資料 | 読み取りたいObsidian、Google Driveなど。秘密や本文はここへ貼らない |
| 作業 | 調査、相談、文書作成など、最初に実現したい1つの体験 |
| 確認方法 | 眼鏡、本人用Web、Macのどこで何を確認するか |

## コピーして使う依頼

```text
「私のAI V2」の参考資料を読み、自分用の似た仕組みを作るのを手伝ってください。

目的は、眼鏡から自然に話して、MacのAIとの会話と仕事を続けることです。
README、CONCEPT、ARCHITECTURE、BUILD_GUIDE、REFERENCE_SPEC、SAFETYを先に読んでください。
この公開資料には実働版のソース一式やインストーラーはありません。
掲載されたJSON例は説明用で、互換APIではありません。

最初に、私の環境と、現時点で利用できる公式の接続方法を確認してください。
使える接続と未確認の接続を分け、実現可能な構成と、足りない部品を説明してください。
特に、独立したCodex会話への接続と、開いているデスクトップ会話への接続を混同しないでください。

利用者は、質問・依頼・説明を分類せず自然に話します。
固定キーワードで意味理解を狭めず、情報が足りない場合は自然に聞き返してください。
会話先を判断する受付AIには、ファイル操作やスキル実行の権限を与えません。
実作業は、選ばれたMac会話が担当します。

まず専用のテスト会話へ文字を1回送り、完了状態と本文を読める最小構成を作ってください。
それから依頼状態の保持、認証付き眼鏡表示、実音声、会話先確認、既存会話への接続、
進捗・結果・聞き返しの共有、確認後の変更、復旧・終了へ段階的に進めてください。

実会話ID、対象、表示した質問、元の依頼、送信状態はMac側で照合します。
通信の結果が不明な依頼を自動再送しないでください。
古い質問への返答や、文脈に合わない音声認識を、同意として使わないでください。
原音と一時音声を処理後に削除し、生成Agentへ有効な秘密を埋め込まないでください。

保存・編集・送信・公開などの実行直前には、対象・内容・影響を示し確認を受けてください。
使用する道具やスキルの権限とルールは維持してください。
新規契約、課金、外部公開、本番設定の変更を、最小構成の準備に混ぜないでください。

端末操作を頼む前にMacで準備できることを済ませ、目的・操作・所要時間を説明してください。
模擬確認、Mac確認、実機の音声・表示確認を分けて報告し、合格済みの操作を繰り返さないでください。
自分の環境で確認していないものを、再現済みや完成と報告しないでください。
```

この依頼文は、認証、権限、実機検証の代わりにはなりません。AIの提案したAPIや権限が実在するかを公式資料と自分の環境で確認し、必要な部品を作ります。
