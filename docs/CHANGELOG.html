変更履歴

この履歴は公開資料の版です。個人用AgentやMacサービスのアプリ版とは別に管理します。

docs-v2.0.6 — 2026-10-12

  • 利用場面、タップ操作、チャットの関係、確認のタイミング、スマホ中継、確認済み範囲を伝える図解6枚を追加。PNGと編集用SVGを収録し、既存の構成図は保持。
  • 採用した文章の見直し24件と構成案4件を反映。参考公開の条件を冒頭に示し、用途・操作・用語の順に整理。確認する人と各部品の役割を明確にした。
  • 「閉じた眼鏡」は、既存の検証記録と実装で意味を確認し、「私のAI」を終了した状態と明記。終了中への通知は未確認のままとした。
  • 正本文書からREADMEと補助HTMLを再生成。公開資料の編集のみで、個人用アプリ、Macの稼働環境、眼鏡の動作や設定は変更していない。

docs-v2.0.5 — 2026-10-10

  • スマホ経由の通信条件として、スマホのインターネット接続とHi Rokidが起動して眼鏡と接続・通信できる状態を明記。
  • AIUI公式のBluetooth経由のスマホ中継を参照し、テザリングが必須に見える表現を訂正。
  • 紹介、仕組み、再現の手引き、仕様、制約、AI依頼文、参照資料と図を更新。アプリ動作は変更していない。

docs-v2.0.4 — 2026-10-10

  • 録音開始・終了・継続の説明を、テンプルのタップ回数まで具体化。
  • 利用アプリ名をChatGPTデスクトップアプリ、作業画面をChatGPT Workとして訂正。内部接続の技術名は補足で区別。
  • チャット・スレッド・プロジェクトの意味と関係を説明し、継続する相談先を「チャット」と表記。
  • 実画面の「続ける会話」などは保持し、その表示が相談先チャットを指すと説明。
  • 図、全10文書、README、補助HTML、ダウンロード資料を更新。アプリの動作は変更していない。

docs-v2.0.3 — 2026-10-10

  • 一般事務職を基本の読者として、紹介と全10文書を読み直して書き直した。
  • 冒頭を用途・操作・V1との差・利用条件の順に整理し、会話例を資料調査や説明資料の作成場面へ変更。
  • 仕組みの図と本文を日常の言葉で説明。技術仕様とデータ例は任意で開く補足へまとめた。
  • 自分用に作る手引きとAIへの依頼文を、目的・条件の整理から相談できる内容へ変更。
  • GitHubの同じREADME内で読む方法を維持し、作る手引きなどは折りたたみ表示。既存の補助HTMLも同じ正本から更新。
  • 公開資料の編集のみ。個人用アプリ、Macの稼働環境、眼鏡の動作は変更していない。

docs-v2.0.2 — 2026-10-10

  • 元のGitHub内で読めるよう、各説明の全文をREADMEへ収録し、目次と関連リンクを本文へのページ内リンクに変更。
  • 別の閲覧サイトへ移る案内をトップの必須導線から除き、既存のGitHub URLで読める構成に修正。
  • 正本の文書からREADMEを生成し、個別文書との本文のずれを防ぐ。

docs-v2.0.1 — 2026-10-10

  • GitHubのファイル一覧が本文を覆う閲覧上の問題に対応し、GitHub Pagesの閲覧用ページを追加。
  • トップページの説明リンクを、各資料の本文が直接開くページへ変更。
  • 公開Markdownを正本とし、12ページのHTMLを同じ内容から生成。資料の内容とアプリ動作は変更しない。
  • 閲覧用ページは狭い画面でも本文を表示し、ファイル一覧の開閉操作を不要にした。

docs-v2.0.0 — 2026-10-10

  • V1を残し、V2のコンセプトと再現情報を新しいリポジトリで参考公開。
