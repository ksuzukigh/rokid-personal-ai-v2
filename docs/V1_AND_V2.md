# V1とV2の違い

V1から引き継いだのは、眼鏡からAIへ自然に話しかけることです。V2では、MacのChatGPT Workで普段使っているチャットにつなぎ、相談や仕事の続きを進めることを中心にしました。

## 変わったこと

| 観点 | V1 | V2 |
| --- | --- | --- |
| チャットの場所 | 眼鏡向けに用意したチャットで進める | Macで普段使っているチャットを選んで進める |
| 続け方 | 眼鏡のチャットの中で、前のやり取りを踏まえて続ける | 今の相談、別の相談、新しい相談を選び、Macからも続ける |
| 調査や文書作成 | 専用の仕組みで、決められた範囲の作業をする | 選んだMacのチャットが使える資料や道具で進める |
| 眼鏡の表示 | 返事を読むことが中心 | チャット名、使っているAI、途中経過、質問、返事を表示する |

V1にも調査や、確認後の保存・編集はありました。V2の特徴は、**普段のMacの相談や作業を、眼鏡から引き継いで続けること**です。

## V1の資料を残す理由

[V1の公開資料](https://github.com/ksuzukigh/rokid-personal-ai)は、最初にどんな仕組みを作り、そこからどう発展させたかを知る資料として残しています。以前の記事やリンクから来た人も、当時の内容を読めます。

V1の説明は「できること」「使い方」「仕組み」の順に案内していました。V2の公開資料も、技術に詳しくない方が利用場面から理解できる順序を基本にしています。

## 資料を使い分けるとき

V1の操作手順や制限は、当時のものです。V2では、「タップして話す」または「タップして続けて話す」と表示されたら、テンプルを1回タップして録音を始めます。現在の使い方はV2の説明を参照してください。

V1には参考コードがありますが、それを使えばV2になるわけではありません。V2は考え方と作るための資料を公開しており、実際に動かしているプログラム一式は含めていません。
