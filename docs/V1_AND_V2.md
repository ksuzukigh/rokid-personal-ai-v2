# V1とV2の関係

[V1の公開リポジトリ](https://github.com/ksuzukigh/rokid-personal-ai)は、眼鏡からMacのAIへ話しかける仕組みと、その構成を読むための参考コードを残しています。V2はその発展として、Macの普段の会話と仕事を眼鏡から続ける設計を紹介します。

## 残す理由

V1には、音声をMacへ送って文字化する、返事を眼鏡へ戻す、確認後に限られた保存・編集を実行する、という土台があります。V2が何を引き継ぎ、何を変えたかを理解する資料になります。

V1の記事やリンクから来た人も、当時の説明を読めるよう、既存リポジトリとURLを残します。V2は別リポジトリにし、両者から相互に案内します。

## V2で変えた中心部分

| 観点 | V1 | V2 |
| --- | --- | --- |
| 会話の続き先 | 眼鏡向けの専用会話処理 | Macの通常の会話 |
| 会話の選択 | 専用の会話の中で継続 | 現在の続き、別の会話、新しい会話を自然に判断 |
| 調査・文書作業 | 専用の処理と制限された操作 | Mac会話が持つ道具・スキルを使う |
| 受付の役割 | 眼鏡向けの処理をまとめる | 意味理解と会話先の提案。実作業は担当しない |
| 表示 | 音声往復と回答を中心に構成 | 実会話名、実モデル、途中経過、最終回答、Mac側の新質問を共有 |

V1にも調査と保存・編集機能があります。「V1は質問だけ、V2は作業もできる」という区分ではありません。

## コードを混ぜない

V1のコードはV1の参考実装です。V2の資料に書かれた会話接続や端末登録が、V1のコードへ実装済みであるとは限りません。

V2の公開資料には、個人用実装のソースやGit履歴を持ち込んでいません。説明用の仕様とデータ例から、自分の環境に合った部品を組み立てます。V1の制限や操作文言を、V2の現行仕様として流用しないようにしてください。
