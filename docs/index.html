私のAI V2

Macで相談していた仕事の続きを、眼鏡から声で進める。

「私のAI」は、マイクとディスプレイを備えたRokidのスマートグラスから、MacのChatGPTデスクトップアプリで進めている相談や仕事を続ける、鈴木啓一の個人開発プロジェクトです。作者は、調査や文書作成などを進めてもらうChatGPT Workを使っています。

このページは、一般事務職の方をはじめ、プログラミングに詳しくない方に向けて書いています。何に役立つのか、どう使うのか、なぜ作ったのかを紹介します。自分でも似た仕組みを作りたい方へ、AIや開発を手伝う人と相談するための資料も用意しました。

まずここだけ読む

どんなことに役立つのか

Macで資料を調べたり、文書の下書きをAIと相談したりしていると、席を離れてから追加の考えが浮かぶことがあります。「さっきの資料に、この点も入れたい」と眼鏡へ話しかけて、その相談を続けられるようにしました。

AIが確認したいことを聞いてきたら、声で答えます。途中経過や返事は眼鏡に表示されます。机に戻ったら、同じMacのチャットを開いて、資料を見ながら作業を続けられます。

V2で大切にしたのは、眼鏡とMacで同じChatGPT Workのチャットを続けられることです。

チャット・プロジェクト・スレッドとは

ここでいうチャットは、ChatGPTの画面に残る、AIとの一続きのやり取りです。「説明資料の下書き」などの名前が付いた相談を、あとから開いて続けられます。

言葉 この資料での意味
チャット 一つの相談や仕事について、依頼とAIの返事を積み重ねる場所
スレッド 一続きのやり取りを指す呼び方。この資料では「チャット」と表記する
プロジェクト 関連するチャット、資料、作業の指示を目的ごとにまとめる場所

たとえば「業務改善」というプロジェクトに、「説明資料の下書き」「参考情報の調査」というチャットを分けて置きます。眼鏡から「説明資料の続きを考えたい」と話すと、続けるチャットを選び、そのやり取りを踏まえて進めます。

「Macで普段使っているチャット」とは、このようにChatGPTデスクトップアプリで開いて使う、個別の相談や仕事を指します。 プロジェクトに入れていないチャットもあります。

どう使うのか

  1. 眼鏡で「私のAI」を開き、「タップして話す」と表示されたら、テンプル（眼鏡のつるにあるタッチ部分）を1回タップして話します。
  2. 話し終えたら、テンプルをもう1回タップして録音を終えます。
  3. 別の相談の続きを始めるときや、新しい相談を作るときは、画面のチャット名を確認します。
  4. AIの返事を読みます。「タップして続けて話す」と表示されたら、テンプルを1回タップして、続きを話します。

アプリを開いただけでは録音しません。文書を保存・編集する前には、対象と内容を示して確認を受ける設計です。

V1から何が変わったのか

V1でも、眼鏡からAIとのチャット、調査、確認後の文書保存ができました。V2では、Macで普段使っているチャットを選び、その相談や作業を続けることを中心にしました。これまでのやり取りや、Macで利用できる資料・道具を使って進めます。

利用には何が必要か

作者が確認したのは、Rokid AI Glasses RV101とMacを使う個人環境です。利用中はMacが起動してログインしており、眼鏡とMacが必要な通信をできる状態にしておきます。外出先でスマホ経由で使う場合は、スマートフォンがインターネットにつながり、Hi Rokidアプリが起動して眼鏡と接続し、通信できる状態になっていることが必要です。Bluetoothでつながったスマホの回線を使えるため、テザリングは必須ではありません。

この公開ページで提供するのは、考え方と作るための参考資料です。 完成したアプリやインストーラーは配布していません。似た仕組みを作るには、自分の環境に合わせた開発と確認が必要です。

眼鏡の小さな画面では長い文書を確認しづらいため、詳しい確認や仕上げにはMacも使います。ほかの人の環境で同じように動くことは、まだ確認していません。

読みたいところから

ここまでで概要がわかります。以下は、関心のあるところだけ読んでください。GitHubの目次リンクは、このページ内の説明へ移動します。

  • チャットとタップの例：資料調査や文書作成を、どう頼むのか。
  • コンセプトと設計の理由：なぜ、Macの相談を眼鏡から続けるのか。
  • 仕組みをやさしく説明：眼鏡とMacは、それぞれ何をするのか。
  • 安心して使うための考え方：録音、保存前の確認、聞き違いをどう扱うのか。
  • 確かめたことと、まだできると言えないこと：実際に確認した範囲と制約。
  • V1とV2の違い：引き継いだこと、変えたこと。

似た仕組みを作ってみたい方には、次の資料もあります。

  • 自分用に作るための進め方：最初に目的と条件を整理する。
  • AIに相談するための依頼文：自分の環境を書いて相談する。
  • 詳しい仕様とデータ例：実装担当者向けの折りたたみ資料。

作るための資料は、必要な方だけ開いてください。コンセプトを知りたい方は読まなくても構いません。

公開資料について

やり取りの例は説明のために作った架空の例です。作者が実際に確認したことは、別に確認した範囲へまとめています。

個人のチャット、録音、文書、通信先、認証情報は掲載していません。V1の資料は、開発の前段階を知るために残しています。
